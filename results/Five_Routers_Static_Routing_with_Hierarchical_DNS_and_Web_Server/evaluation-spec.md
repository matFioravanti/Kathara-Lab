# Evaluation Specification

## Requested deliverable

Generate a lab.

## Topology requirements

- Include exactly five routers.
- Each router must have a maximum degree of three.

## Routing requirement

- Route the network using static routing.

## DNS requirements

- Include three DNS servers:
  - a root DNS server;
  - an `org` DNS server;
  - a local name server.

## Server and client requirements

- Include a server named `kathara.org`.
- Include a client.
- The client must be able to reach the `kathara.org` server by using its name.
