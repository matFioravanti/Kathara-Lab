# Execute the Kathara Mini-Prompts

Read the file `small_prompts1.md`.

Identify all the mini-prompts contained in the file and execute them one at a time, following the exact order in which they appear.

For each mini-prompt:

1. Read the complete text.
2. Execute it without modifying, summarizing, or merging it with other prompts.
3. Follow all instructions already included in the mini-prompt, including:
   - `Do not inspect other directories in this workspace.`
   - `Use the Skill.md in the kathara-lab-creation folder.`
4. Save the generated files in a separate folder inside the `prompts_generates` directory.
5. Use the folder name generated for that lab, then append the scenario number and version to it.

Required folder naming format:

`prompts_generates/<generated-folder-name>_<scenario-number>_version_<version>`

Examples:

- `ipv4_static_routing_lab_01_version_A`
- `ipv4_static_routing_lab_01_version_B`
- `ipv6_dns_lab_02_version_A`
- `ipv6_dns_lab_02_version_B`

The original generated folder name must be preserved. The scenario number and version must only be added to the end of that name.

Version A and Version B of the same scenario must be executed separately and saved in different folders.

Do not skip any mini-prompt.

Do not execute multiple mini-prompts at the same time.

Complete each mini-prompt before moving to the next one.

Continue until all mini-prompts in `small_prompts1.md` have been executed.
