design a Kathara lab with a tree topology of three routers. A root router connects to two child routers over dual-stack point-to-point links. Each router serves one LAN. All routers, PCs, and the LAN interfaces must carry both IPv4 and IPv6 addresses. Routing tables must be configured statically for both address families. Each child router uses a static default route for both IPv4 and IPv6 pointing toward the root. The root must have explicit static routes for each child LAN in both address families. All PCs must be able to reach each other using either IPv4 or IPv6.
